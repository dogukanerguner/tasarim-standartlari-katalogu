İngilizce prompt · detaylı
Design a health tracking dashboard in soft neumorphism. Single background color (#e4e9f2) used for every surface. Elements are defined only by paired shadows: 8px 8px 18px #c5cbd8 and -8px -8px 18px #fbffff for raised, the same values inset for pressed. 18—28px radii everywhere. A circular progress ring built from an inset well plus a conic gradient, soft pill toggles, an inset track progress bar and a muted blue-grey accent (#8fa4d6). Type is dark slate blue, low contrast, calm.
