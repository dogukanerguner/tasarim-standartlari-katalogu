## Hacker News — Show HN

**Title:** Show HN: If Da Vinci designed an app — 72 design languages as live pages + AI prompts

**Text:** I turned 72 design languages — from Bauhaus and Swiss grid to Linear-style
dark SaaS, from Monet and Hokusai to Bloomberg-terminal density — into working
HTML pages. Each page is three things at once: a live example, a copy-paste
generation prompt (palette, typography, layout rules, and a crucial "avoid" list),
and a machine-readable JSON layer, so you can tell Claude/Cursor "build this in
style 67" and it actually works. There's also a gallery rendering the exact same
to-do screen in all 72 styles, a style-personality quiz, a mixer that blends any
two styles into one prompt, and a zero-dependency MCP server. The site's UI is
Turkish/English; all prompts are English. MIT licensed.
