# 48 — Araç-Merkezli Editör

Figma tarzı: sessiz UI kromu, yıldız olan canvas; Inter tipografisiyle piksel hassasiyeti.

## Prompt (EN)

Design a Figma-like vector editor where the chrome stays quiet and the canvas is the star. Top 48px dark toolbar (#2c2c2c) with tool icons, centered file name, share button and overlapping avatar circles. Left 240px layers panel: indented layer tree with eye icons, selected row tinted #18a0fb. Center: #e9e9e9 canvas holding a white artboard with a simple poster composition; the selected circle gets a #18a0fb selection frame, 8 square handles and a "164 × 164" size label. Right 240px properties panel with X/Y/W/H inputs, a fill row, an opacity slider. Inter font (designed by Rasmus Andersson for UI text) at 11-12px, text #333333, white panels. No ornament, no gradients in chrome, no big type, no showy shadows.

## Brief (TR)

Koyu toolbar, katman ağacı, artboard'lu canvas ve özellik paneliyle sessiz kromlu bir vektör editörü; tek accent #18a0fb, font Inter.

## Kurallar

- **Tipografi:** Inter 400/500/600; 11-12px yoğun UI metni, mono sayısal değerler
- **Düzen:** 48px toolbar + 240px katman paneli + canvas + 240px özellik paneli
- **Hareket:** Anlık seçim geri bildirimi; animasyon değil tepkisellik
- **Kaçınılacaklar:** Süs, kromda gradyan, büyük tipografi, gölge şovu
