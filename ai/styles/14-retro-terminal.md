# 14 — Retro Terminal

Komut satırı düzeni, tek renk paleti ve tamamen kod tabanlı geliştirici estetiği.

## Prompt (EN)

Design a developer deployment tool page as a monochrome terminal. Near-black green-tinted background (#050a06) with phosphor green text (#41ff7e), CRT scanlines and a soft radial glow. A large ASCII-art wordmark, a live command session with progress bars in amber, a bordered live log table of HTTP requests, an uptime panel and a bar chart made of solid blocks. Everything is IBM Plex Mono, all panels are 1px green rules, one blinking block cursor.

## Brief (TR)

ASCII logo, canlı komut oturumu ve fosfor yeşili tek renk paletiyle kurulmuş terminal arayüzü.

## Kurallar

- **Tipografi:** IBM Plex Mono 400/600, 14px, 1.7 satır yüksekliği
- **Düzen:** Tek sütun konsol + sağda dar panel kolonu
- **Hareket:** 1.1 sn imleç yanıp sönmesi
- **Kaçınılacaklar:** Renkli ikon, yuvarlak köşe, gölge, resim
