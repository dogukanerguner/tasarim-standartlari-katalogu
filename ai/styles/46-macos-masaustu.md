# 46 — macOS Masaüstü

Trafik ışıkları, yarı saydam kenar çubuğu ve üç panelli sükûnet; içerik önde, krom geride.

## Prompt (EN)

Design a calm macOS-style desktop mail app window in the Apple HIG language. Grey-blue gradient desktop (#e8eaf0), floating window (#f5f5f7) with 12px radius and one large soft shadow. Traffic lights (#ff5f57 #febc2e #28c840) on a unified toolbar with a search field and soft icon buttons. Three panes: a translucent sidebar with colored-dot folders, a 280px message list with sender, subject and two-line previews, and a white reading pane with an avatar header and a single #0a84ff Reply button. Use -apple-system at 13px for dense UI text, 600-weight headings, rgba(0,0,0,.08) hairline dividers. No sharp corners, no heavy shadows, no menu bar inside the window.

## Brief (TR)

Trafik ışıklı, yarı saydam kenar çubuklu, üç panelli sakin bir macOS posta penceresi; tek accent renk ve içerik-önce hiyerarşi.

## Kurallar

- **Tipografi:** -apple-system / BlinkMacSystemFont; 13px UI metni, 600 başlıklar
- **Düzen:** Üç panelli pencere: kenar çubuğu + liste + okuma paneli, birleşik toolbar
- **Hareket:** Yumuşak seçim geçişleri; abartısız, sistem hızında
- **Kaçınılacaklar:** Keskin köşe, ağır gölge, Windows menü çubuğu, renk kalabalığı
