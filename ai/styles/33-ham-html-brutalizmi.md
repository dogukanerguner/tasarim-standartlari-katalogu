# 33 — Ham HTML Brütalizmi

Tarayıcı varsayılanları, mavi bağlantılar, tek sütun ve sıfır süsleme.

## Prompt (EN)

Design a personal homepage using only default browser styling. White background, Times New Roman, 16px, a single 900px column. Blue underlined links, purple visited links. Horizontal rules as section dividers, an ordered list table of contents, a bordered HTML table of posts, a blockquote with a left border, and a monospace pre block listing page weight and request count. No custom fonts, no images, no JavaScript, no decoration of any kind.

## Brief (TR)

Tarayıcı varsayılanlarıyla yazılmış, tek sütunlu, mavi bağlantılı ve tamamen içerik odaklı kişisel sayfa.

## Kurallar

- **Tipografi:** Times New Roman 16px + Courier New (pre)
- **Düzen:** Tek sütun, max 900px, hr ayırıcılar
- **Hareket:** Yok
- **Kaçınılacaklar:** Özel font, gradyan, ikon, animasyon, çerçeve
